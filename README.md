# Statewise

An Indian states and union territories quiz. Identify one region from three progressively easier clues, place your pin, and answer within two minutes.

- All 28 states and 8 union territories are selectable.
- Correct answers earn 100, 60, or 30 points based on clues revealed.
- A single 120-second timer runs across all clues.
- Correct/wrong callouts appear on the chosen region.
- This prototype contains one question.

## Hosting

GitHub Pages serves the `main` branch root. No build step is required. For local preview, run `python3 -m http.server 4173` in this folder.
